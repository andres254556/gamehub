THE HOUSE BELOW — publish-ready website

This folder is a static website. The main game is index.html.

PUBLISH WITH NETLIFY:
1. Open https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the unzipped folder (the_house_below_publish) onto the page.
4. Wait for Netlify to finish. It will give you a public website link.
5. Open that link to test the game and share it with friends.

IMPORTANT:
- Keep an internet connection while playing; the 3D engine loads from a public CDN.
- The game is designed for a desktop browser with a keyboard and mouse.
- If you change the game later, upload the updated folder again.
